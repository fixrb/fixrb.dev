Fix 1.0をリリースしました

2026年10月31日 · Cyril Kato

Fix 1.0を公開しました。Fixは、テストスイートが仕様であるRubyのテストフレームワークです。仕様とは、サブジェクトが何をMUST（しなければならない）、SHOULD（すべきである）、MAY（してもよい）かをRFC 2119の言葉で述べ、サブジェクトがどう作られているかには触れない文書のことです。2014年に大阪で書き始め、それから何度も作り直してきました。これが、完成したと思える最初のバージョンです。

アヒルのように鳴くなら

Rubyは、アヒルをその振る舞いで見分けます。それがダックタイピングです。Fixの仕様も同じで、クラスを名指しせず、ファイルの最後のテストがサブジェクトを選びます。ここでは、アヒルとゴムのアヒルを、ひとつの仕様に照らします。

require "fix"

Fix :Duck do
  on :quack do
    it MUST eq "Quack!"
  end

  on :swim do
    it SHOULD eq "Splash!"
  end

  on :fly do
    it MAY be_true
  end
end

class Duck
  def quack = "Quack!"
  def swim = "Splash!"
  def fly = true
end

class RubberDuck
  def quack = "Quack!"
  def swim = "Splash!"
end

exit([
  Fix[:Duck].test { Duck.new },
  Fix[:Duck].test { RubberDuck.new }
].all?)

ruby duck_fix.rb
duck_fix.rb:5: Success: expected "Quack!" to eq "Quack!"
duck_fix.rb:9: Success: expected "Splash!" to eq "Splash!"
duck_fix.rb:13: Success: expected true to be true
duck_fix.rb:5: Success: expected "Quack!" to eq "Quack!"
duck_fix.rb:9: Success: expected "Splash!" to eq "Splash!"
duck_fix.rb:13: Info: NoMethodError: undefined method 'fly' for an instance of RubberDuck

ゴムのアヒルは飛べませんが、飛ぶことはMAYにすぎなかったので、その行はInfoとなり、どちらのアヒルも仕様を満たします。3つのレベルが、必須のもの、推奨されるもの、任意のものを分け、行は期待ごとに1行ずつ、何が起きたかを正確に伝えます。全体が満たされたかどうかは、プロセスの終了ステータスが伝えます。同じ仕様で、自分のクラスも、依存しているライブラリも、そのどちらかの次のバージョンもテストできます。

1.0がもたらすもの

  • 仕様はファイルの読み込み時に一度だけ組み立てられ、データとして保持されます。誤りがあれば、テストが走る前に例外になります。
  • 各コンテキストは子プロセスで実行されます。サブジェクトがグローバル変数や定数、ENVに対して行ったことはそのコンテキストの中にとどまり、コンテキストの順序が結果を変えることはありません。
  • マッチャーはMatchiのもので、比較を行うのは期待値の側です。テスト対象のオブジェクトが自分で自分を保証することはできません。
  • testは期待ごとに1行を書き、仕様が満たされたかどうかを返します。runは結果をデータとして返します。match?は仕様をマッチャーにするので、仕様はfix(:Name)で別の仕様を求められます。
  • コードは約300行で、テストは手で書き、カバレッジは100%です。Ruby 3.3、3.4、4.0で動き、4つの小さなgem、matchi、spectus、aw、defiの上に成り立っています。どれも、信頼する前に読めるほど短いものです。
  • その周りには、プロジェクトのファイルを実行するfix-command、itsという語を加えるfix-its、仕様をほかのどのテストフレームワークにも持ち込むmatchi-fixがあります。

試してみる

gem install fix-command

それからガイドへ。最初の仕様、言語、ひとつずつのマッチャー、コマンド、そしてRSpecから移るときに変わることです。ページにあるすべての例は、公開する前に実行しています。リファレンスはREADMEです。FixにはRuby 3.3以降とfork(2)が必要です。

手元にあるものについて仕様を書き、それが何を言うかを見てください。Fixは、そのためにあります。
