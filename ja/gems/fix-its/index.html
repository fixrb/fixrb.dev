fix-its

Fixのためのitsという語。サブジェクトのメソッドとその期待を1行で。

Fix::Itsは、fixの言語にitsという語を加えます。サブジェクトのメソッドとその戻り値についての期待を1行で書けます。its(:size) { MUST eq 3 }はon(:size) { it MUST eq 3 }と同じで、結果はitsの行を指します。ガイドではitsという語で紹介しています。

インストール

Gemfileにgem "fix-its"を加えるか、gem install fix-itsを実行し、fixをrequireするrequire "fix/its"を書いてください。

使い方

itsは、onと同じくメソッドの名前とその引数をとり、さらに要求（レベルとマッチャー）を与えるブロックをとります。onやwithの中では、そのコンテキストの値にメソッドを送ります。

require "fix/its"

Fix :Word do
  its(:size) { MUST eq 5 }
  its(:upcase) { MUST eq "HELLO" }
  its(:start_with?, "he") { MUST be_true }

  on :chars do
    its(:first) { MUST eq "h" }
  end
end

exit(Fix[:Word].test { "hello" })

ruby word.rb
word.rb:4: Success: expected 5 to eq 5
word.rb:5: Success: expected "HELLO" to eq "HELLO"
word.rb:6: Success: expected true to be true
word.rb:9: Success: expected "h" to eq "h"

ブロックはonのコンテキストで、文書のほかの部分と一緒に一度だけ読まれ、最後の式が要求になります。それ以外のものを与えるブロックは、ブロックがない場合と同じく、読み込み時にArgumentErrorを発生させます。itsは言語の語なので、letにこの名前はつけられません。Ruby 3.4以降、ブロックの中の裸のitはブロックのパラメーターです。its(:size) { MUST eq it }はeq nilを作ってしまうので、値を書いてください。
