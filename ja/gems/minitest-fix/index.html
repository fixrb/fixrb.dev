minitest-fix

値をFixの仕様でテストする、minitestのアサーション。

Minitest::Fixは、minitestのテストにふたつのアサーションを加えます。assert_fix :Name, valueは、値がfixの仕様のすべての期待を満たすときに成功し、満たさない期待は、メッセージに1行ずつ示されます。refute_fixはその逆です。minitestのテストスイートをそのまま残して、Fixの仕様を加えるための方法です。RSpecにはrspec-fixがあります。

インストール

テストスイートのGemfileにgem "minitest-fix"を加え、fixをrequireするrequire "minitest/fix"を書き、テストクラスでinclude Minitest::Fixしてください。テストスイートのすべてのテストで使うには、Minitest::Testそのものにincludeします。このgemがminitestに求めるのは、そのクラスのassertとrefuteだけです。

使い方

名前はFix :Name do … endで登録された仕様のもので、なければKeyErrorが発生します。テストスイートの中ではminitest/autorunがテストを実行します。下のファイルは、テストをひとつずつ手で実行しているので、レポートのシード値や時間を含まない、アサーションのメッセージだけを出力します。

require "minitest"
require "minitest/fix"

Fix :Duck do
  on :walk do
    it MUST eq "Klop klop!"
  end

  on :swim do
    it SHOULD eq "Swoosh..."
  end

  on :speak do
    it MAY eq "Quaaack!"
  end
end

class Duck
  def walk = "Klop klop!"
  def swim = "Swoosh..."
  def speak = "Quaaack!"
end

class Robot
  def walk = "Klop klop!"
  def swim = "Glug glug..."
end

class RubberDuck
  def swim = "Swoosh..."
  def speak = "Squeak!"
end

class DuckTest < Minitest::Test
  include Minitest::Fix

  def test_duck = assert_fix(:Duck, Duck.new)
  def test_robot = assert_fix(:Duck, Robot.new)
  def test_rubber_duck = assert_fix(:Duck, RubberDuck.new)
end

# minitest/autorun would run the tests and write its report, with a seed and
# times; here each test is run by hand, so that the file writes the same lines
# every time.
DuckTest.new("test_duck").run.passed?  # => true
DuckTest.new("test_robot").run.passed? # => true

puts DuckTest.new("test_rubber_duck").run.failure.message

ruby usage.rb
Expected the value to fix Duck:
  usage.rb:6: Error: NoMethodError: undefined method 'walk' for an instance of RubberDuck
  usage.rb:14: Failure: expected "Squeak!" to eq "Quaaack!"

assert_fixは、WarningやInfoも含めてすべての期待が成功として扱われれば成功します。ロボットは、泳ぎ方が違い、鳴きもしませんが成功し、minitestはそれについて何も伝えません。すべての行を出力するのはFix[:Duck].test { Robot.new }です。失敗したときは、FailureとErrorの行を、それぞれの期待の場所とともに示します。refute_fix :Name, valueは、期待がひとつでも満たされなければ成功し、どちらもアサーション1回として数えられます。受け取るのは値で、ブロックではありません。値は一度だけ与えられるので、アサーションのための仕様はwithなしで書きます。

テストのプロセス

仕様のメソッドは、テストのプロセスの中で、値そのものに送られます。そこにはテストのトランザクションも、モックも、カバレッジツールもあります。値を変えるメソッドは、続くコンテキストとテストの残りの部分にとっても、その値を変えます。assert_fix :Name, value, fork: trueは、Fixと同じように、各コンテキストを子プロセスで実行します。メソッドは値のコピーに送られ、テストが持っている値はそのまま残ります。これは、状態がすべてプロセスの中にある値のためのものです。プロセスの外にあるものはコピーされないからです。トランザクションを使うテストのRailsアプリケーションでは、子プロセスにはテストが作った行が見えず、子プロセスが書いた行はロールバックされません。モックには、子プロセスが受け取った呼び出しが見えません。
