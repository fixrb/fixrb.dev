defi

メソッド呼び出しを用意し、どのオブジェクトにも送る。

チャレンジとは、ドットのあとに書くとおりのメソッド名と引数のことです。オブジェクトに送ると、呼び出しから出てきたもの、つまりメソッドが返した値か、発生させた例外を持ち帰ります。同じチャレンジをいくつのオブジェクトにも送って、それぞれがそれをどう扱うかを比べられます。

インストール

Gemfileにgem "defi"を加えるか、gem install defiを実行してください。

使い方

チャレンジは位置引数、キーワード引数、ブロックをとり、それらをそのまま渡します。toはそれをオブジェクトに送って値を返します。objectは返ってきたもの、raised?はそれが例外として発生したかどうかを示し、callはオブジェクトを返すか、例外を再び発生させます。

require "defi"

challenge = Defi::Challenge.new(:fetch, :b, 0)
challenge.to_s # => ".fetch(:b, 0)"

value = challenge.to({ b: 2 })
value.raised? # => false
value.object  # => 2
value.call    # => 2

value = Defi::Challenge.new(:fetch, :b).to({})
value.raised?     # => true
value.object      # => #<KeyError: key not found: :b>
value.call rescue $!.class # => KeyError

Defi::Challenge.new(:encode, "US-ASCII", undef: :replace).to("café").object # => "caf?"
Defi::Challenge.new(:map) { |n| n * 2 }.to([1, 2]).object # => [2, 4]

チャレンジと値は凍結されています。引数は与えたオブジェクトそのもので、コピーではありません。

返ってくるもの

メッセージはpublic_sendで送られます。privateメソッドを呼ぶ場合や、public_sendをもたないBasicObjectに送る場合は、NoMethodErrorになります。チャレンジは、メソッドがそれ自身で発生させた例外を値として保持します。StandardError、NotImplementedErrorのようなScriptError、SystemStackError、そしてexitのSystemExitです。メソッドのせいではないものは素通りします。Interrupt、シグナル、NoMemoryError、Timeoutがブロックを終わらせるために使う例外、そしてExceptionのそのほかのサブクラスです。

require "defi"

# What a method raises on its own comes back as the value.
Defi::Challenge.new(:+, 1).to("a").object.class     # => TypeError
Defi::Challenge.new(:secret).to(Object.new).object.class # => NoMethodError

exiting = Object.new
def exiting.call = exit(3)
Defi::Challenge.new(:call).to(exiting).object.status # => 3

# What is not the method's doing goes through.
interrupting = Object.new
def interrupting.call = raise(Interrupt)
outcome = begin
  Defi::Challenge.new(:call).to(interrupting)
rescue Interrupt
  :went_through
end
outcome # => :went_through
