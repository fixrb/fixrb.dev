matchi-fix

値をFixの仕様でテストする、matchiのマッチャー。

Matchi::Fixは、名前で登録した、またはブロックで書いたfixの仕様で値をテストします。match?は、値がすべての期待を満たすときに真になります。matchiのマッチャーが使えるところ、つまりspectusや、RSpec cloneのようにmatchiの上に作られたフレームワークに、Fixの仕様を持ち込みます。matchiのマッチャーを受け付けないRSpecとminitestには、rspec-fixとminitest-fixがあります。ガイドでは仕様を組み合わせるで紹介しています。

インストール

Gemfileにgem "matchi-fix"を加えるか、gem install matchi-fixを実行し、fixをrequireするrequire "matchi/fix"を書いてください。

使い方

Matchi::Fix.new(:Name)はFix :Name do … endで登録された仕様を探し、なければKeyErrorを発生させます。Matchi::Fix.new { … }はブロックから仕様を作ります。match?はブロックを一度だけ呼び、その値がすべての期待のサブジェクトになります。各コンテキストは、Fixと同じように子プロセスで実行されます。to_sは仕様の名前を示します。

require "matchi/fix"

Fix :Duck do
  on :walk do
    it MUST eq "Klop klop!"
  end
end

class Duck
  def walk = "Klop klop!"
end

matcher = Matchi::Fix.new(:Duck)
matcher.match? { Duck.new }  # => true
matcher.match? { "a decoy" } # => false
matcher.to_s                 # => "fix Duck"

Matchi::Fix.new { it MUST be_a_kind_of Numeric }.match? { 42 } # => true

Spectus.must(matcher).call { "a decoy" }.to_s # => "Failure: expected \"a decoy\" to fix Duck"

match?は、WarningやInfoも含めてすべての期待が成功として扱われればtrueを、ひとつでもFailureかErrorがあればfalseを答えますが、どれかは伝えません。それを伝えるのはFix[:Name].test { … }です。値は一度だけ与えられるので、マッチャーのための仕様はwithなしで書きます。Fix::Specはそれ自体がすでにマッチャーで、Fixの仕様の中ではfix(:Duck)という語がそのマッチャーです。このクラスは、同じものをほかのフレームワークのためにmatchiの語として用意したものです。
