このページでは、lib/greeting.rbにクラスを、fix/greeting_fix.rbにその仕様を置いた小さなプロジェクトgreetingを作ります。

インストール

gem install fix-command

fix-commandはfixも一緒にインストールします。fix gemは仕様の言語を、fix-commandは仕様を実行するfixコマンドを持っています。Gemfileのあるプロジェクトでは、代わりにgem "fix-command"をGemfileに加えてbundle installを実行し、このガイドのコマンドはbundle execを通して実行してください。

仕様

仕様はプロジェクトのfixディレクトリに、ふつうは1ファイルにひとつずつ、名前が_fix.rbで終わるファイルに置きます。fix/greeting_fix.rbには次のように書きます。

require "fix"
require_relative "../lib/greeting"

Fix :Greeting do
  on :call, "Alice" do
    it MUST eq "Hello, Alice!"
  end
end

exit(Fix[:Greeting].test { Greeting.new })
  • require "fix"はFixを読み込みます。require_relative "../lib/greeting"はクラスを読み込みます。クラスが必要なのは最後のテストで、仕様には必要ありません。
  • Fix :Greeting do … endは仕様を組み立て、Greetingという名前で登録します。そのブロックは、ファイルの読み込み時に一度だけ読まれます。
  • on :call, "Alice"はコンテキストを開きます。サブジェクトに送るメソッドcallと、その引数です。
  • it MUST eq "Hello, Alice!"は戻り値についての期待で、要求レベルMUSTとマッチャーeqからなります。
  • 最後の行は、サブジェクトを仕様に照らしてテストします。そのブロック、つまりサブジェクトブロックが、期待ごとに新しいサブジェクトを作ります。testは期待ごとに1行を書き、すべてが満たされたかどうかを返します。exitはそれをプロセスの終了ステータスにします。

仕様はクラスを名指ししません。挨拶が何をするかを述べるだけで、何をテストするかは最後の行のテストが選びます。明日は同じ仕様で別のクラスをテストすることもできます。

コード

lib/greeting.rbに置く、クラスの最初の版です。

class Greeting
  def call(name) = "Hello #{name}!"
end

最初の実行

仕様ファイルはRubyのプログラムです。プロジェクトのルートからrubyで実行すると、各行はそこからのパスでファイルを示します。

ruby fix/greeting_fix.rb
fix/greeting_fix.rb:6: Failure: expected "Hello Alice!" to eq "Hello, Alice!"

期待ごとに1行です。場所（そのitのファイルと行）、判定（Failure）、そして何が起きたか（expected ACTUAL to eq EXPECTED）。カンマが抜けています。プロセスの終了ステータスは、失敗したプログラムと同じく1です。端末にもRakefileにもCIサービスにも、知る必要があるのはそれだけです。

成功させる

lib/greeting.rbにカンマを加えます。

class Greeting
  def call(name) = "Hello, #{name}!"
end

今度は、プロジェクトのルートからfixコマンドを実行します。

fix
fix/greeting_fix.rb:6: Success: expected "Hello, Alice!" to eq "Hello, Alice!"
1 file met

期待が満たされました。fixはfixディレクトリの_fix.rbファイルをそれぞれ専用のプロセスで実行し、その出力をそのまま通して、最後に満たされたファイルの数を示します。すべてが満たされれば終了ステータスは0です。ファイルがひとつならrubyと同じことを言うだけですが、50個あるなら、これが実行すべきコマンドです。

これでひと回りです。仕様はサブジェクトがすべきことを述べ、テストがサブジェクトを選び、終了ステータスがそれを満たすかどうかを伝えます。次のページでは、複数のコンテキスト、パラメーター、そして残り2つのレベルSHOULDとMAYを使って、より豊かな仕様を書きます。
