itsという語

fix-its gemで、メソッドとその期待を1行に。

メソッドと期待をひとつずつもつだけのコンテキストはよくあります。

require "fix"

Fix :Team do
  on :size do
    it MUST eq 3
  end

  on :first do
    it MUST eq "Ada"
  end
end

exit(Fix[:Team].test { %w[Ada Grace Linus] })

fix-itsを使えば、それぞれが1行になります。gem install fix-itsでインストールするか、Gemfileにgem "fix-its"と書き、fixをrequireするfix/itsをrequireします。

require "fix/its"

Fix :Team do
  its(:size) { MUST eq 3 }
  its(:first) { MUST eq "Ada" }
  its(:include?, "Linus") { MUST be_true }
  its(:join, ", ") { MUST eq "Ada, Grace, Linus" }

  on :last do
    its(:length) { MUST eq 5 }
  end
end

exit(Fix[:Team].test { %w[Ada Grace Linus] })

team_fix.rb:5: Success: expected "Ada" to eq "Ada"
team_fix.rb:6: Success: expected true to be true
team_fix.rb:7: Success: expected "Ada, Grace, Linus" to eq "Ada, Grace, Linus"
team_fix.rb:10: Success: expected 5 to eq 5

its(:size) { MUST eq 3 }はon(:size) { it MUST eq 3 }と同じで、行はそのitsを指します。

  • itsは、onと同じくメソッドの名前とその引数をとります（its(:join, ", ")）。
  • そのブロックは要求（レベルとマッチャー）を与え、文書のほかの部分と一緒に読まれます。それ以外のものを与えるブロックや、ブロックがない場合は、ファイルの読み込み時にArgumentErrorになります。
  • onやwithの中では、itsはそのコンテキストの値にメソッドを送ります。上の例では、最後の名前の長さです。
  • itsは言語の語なので、letにこの名前はつけられません。

Ruby 3.4以降、ブロックの中の裸のitはそのパラメーターです。its(:size) { MUST eq it }では、itはnilになります。Ruby 3.3ではFixの語で、要求がないためにArgumentErrorを発生させます。値を書いてください。

メソッドと期待がひとつずつならitsを使い、期待が複数あるコンテキストや、中にwithやさらにonがあるコンテキストにはonを使います。
