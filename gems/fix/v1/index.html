Fix guide

Version 1: from a first specification to the tests of a project.

This guide teaches Fix, version 1, one step at a time, each page building on the one before. It assumes you know Ruby, not a test framework: the last page is for those who come from RSpec.

Each page shows files, and what running them writes. Both come from the repository of this site, where every example is run before a page is published: what you read is what Fix 1 does. The outputs are those of Ruby 4.0; a message of Ruby itself, in an error, may read otherwise under another version.

Fix 1 needs Ruby 3.3 or later and fork(2): Linux, macOS and the BSDs, not Windows or JRuby.
