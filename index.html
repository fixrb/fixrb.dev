Fixrb

A collection of Ruby testing libraries designed to make programmers happy.

Fix is at the heart of it. A specification describes how an object must behave, apart from any implementation. A test then challenges one implementation against it, and the same specification can challenge as many implementations as you need.

Gems

Each gem does one thing, in a few hundred lines of code at most, so that you can read it before you trust it.

The Fix stack

Fix 1.0 is built on Matchi and Aw, and three more gems build on Fix.

  • fix

    Specifications with MUST, SHOULD and MAY requirements, kept apart from the implementations they challenge.

    1.0 in preparation

  • matchi

    Matchers for any test framework, in which the expected value makes the comparison, not the object under test.

    Version 5.0

  • aw

    Runs a block in a forked process and returns its result. Fix uses it to keep contexts apart.

    1.0 in preparation

  • matchi-fix

    A Matchi matcher that checks a value against a Fix specification, from any test framework.

    Moving to Fix 1.0

  • fix-command

    The fix command, to run specification files.

    Moving to Fix 1.0

  • fix-its

    Adds its to specifications, to describe an attribute in one line.

    Moving to Fix 1.0

Outside the stack

Earlier versions of Fix were built on these gems. Fix 1.0 does not use them.

  • defi

    Prepares a method call, a name and its arguments, to send to any object.

  • spectus

    Expectations with the requirement levels of RFC 2119.

  • test_tube

    A test tube to conduct software experiments.

  • expresenter

    Presents the result of an expectation.
