The main gem of Fixrb

Fix

Specifications for Ruby, in the words of RFC 2119, tested against any subject.

A specification says what a subject MUST, SHOULD or MAY do, and nothing about how it is made. Write it once, then test an Array against it today, your own class tomorrow, a library you depend on, or the next version of any of them.

  • Read about Fix
Install
gem install fix
Version
1.0.0, for Ruby 3.3 or later
Source
github.com/fixrb/fix, MIT license

What makes Fix different

  • A specification is a document

    It is read once, when the file is loaded: no setup, no mock, no logic, and anything wrong in it raises before a test runs. It names no class; the test picks the subject.

  • Three levels of requirement

    MUST, SHOULD and MAY tell what is required, what is recommended and what is optional. A SHOULD not met is a warning, a MAY on a method the subject lacks is an info, and both pass.

  • One process per context

    Each context runs in a child process. What a subject does to a global, a constant or ENV stays in its context, and the order of the contexts cannot change a result.

Other gems

Fix is built from small libraries and extended by small gems. Each does one thing, in a few hundred lines of code at most, so that you can read it before you trust it.

Around Fix

Gems that extend Fix, or bring its specifications to other test frameworks.

  • fix-its

    Adds the word its to specifications: a method of the subject and its expectation on one line.

    Version 1.0

  • matchi-fix

    A matcher of matchi that tests a value against a specification of Fix, from any test framework.

    Version 4.0

  • fix-command

    The fix command: runs each specification file in a process of its own, and tells how many files were met.

    Version 1.0

Libraries

Building blocks that do not depend on Fix: use them on their own, with any test framework, or to build one. Fix 1.0 is built on spectus, matchi and aw.

  • matchi

    Matchers for any test framework, in which the expected value makes the comparison, not the object under test.

    Version 6.0

  • spectus

    Expectations with the requirement levels of RFC 2119, MUST, SHOULD and MAY, that give a result instead of raising. The engine of Fix 1.0, built on defi.

    Version 6.0

  • aw

    Runs a block in a forked process and returns its result. Fix 1.0 uses it to keep contexts apart.

    Version 1.0

  • defi

    Prepares a method call, a name and its arguments, to send to any object and keep what came back.

    Version 4.0

  • test_tube

    Checks a value, or what a block returns or raises, against a matcher. Built on defi.

    Version 4.0

  • expresenter

    Presents the result of an expectation: success, warning, info, failure or error.

    Version 1.5

Tools

A command to run as it is, rather than a library to build on.

  • brutal

    Writes plain Ruby test files from a YAML manifest, by recording what the code returns in every combination of contexts. Built on aw.

    Version 2.0
